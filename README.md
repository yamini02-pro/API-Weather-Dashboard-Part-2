# SkyFetch Weather Dashboard - Part 1

Simple frontend project to fetch and display current weather using the OpenWeatherMap API.

## Features

- Displays city name, temperature, description, and icon
- Uses Axios to call OpenWeatherMap REST API
- Initial hardcoded city: London

## Usage

1. Add your OpenWeatherMap API key in `app.js` (`apiKey` variable).
2. Open `index.html` in a browser (via local server or file://).

## GitHub Workflow

- Create a public repository on GitHub.
- Create branch `part-1-api-integration`.
- Commit changes with meaningful messages.
- Open a Pull Request to `main` with title and description.
